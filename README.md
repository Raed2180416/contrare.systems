# contrare.systems

Coming-soon site for **mēdes**, a Contrare Systems product. Plain static HTML/CSS/JS, no build step, served by GitHub Pages at https://contrare.systems.

- `index.html`: content
- `styles.css`: strata design system (the page descends from surface to floor)
- `app.js`: the seam reader, living figure (canvas crowd), held-fixed physics figure, read-in-context, depth gauge

Preview locally: `python3 -m http.server 4173`
